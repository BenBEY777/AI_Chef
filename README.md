# AI_Chef
Използвани технологии и езици

- Програмен език: Python
- База данни: Supabase (PostgreSQL) за съхранение и управление на данни
- Уеб фреймуърк: Streamlit (за изграждане на интерактивния потребителски интерфейс)
- Стилизиране: Custom CSS
- Изкуствен интелект / API: Google Generative AI с модела "gemini-2.5-flash" за анализ на текст и изображения
- Обработка на изображения: Pillow (PIL)
